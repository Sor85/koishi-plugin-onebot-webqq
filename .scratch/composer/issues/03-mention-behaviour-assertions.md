# 03 — 提及的挂载式断言

**What to build:** 提及行为从此可自动验证。目前这些场景只能靠人在浏览器里逐个手点：输入 `@` 后菜单该不该开、键盘选中后是否变成一个整体、按 Escape 会不会误关整个输入区、私聊里会不会冒出菜单。本 ticket 把它们变成挂载式断言，并删掉对应的源码文本断言。

**Blocked by:** 02 — 输入区组件搬迁与草稿光标断言。

**Status:** ready-for-agent

**参考:** `.scratch/composer/spec.md` 的 Testing Decisions「要测的行为」一节。

- [ ] 挂载式断言覆盖：输入 `@` 后菜单开启并带上查询串
- [ ] 方向键改变选中项；回车与 Tab 选中候选并把它变成一个原子 token
- [ ] Escape 只关提及菜单，不影响草稿与其它状态
- [ ] 未传入候选（私聊场景）时菜单不开启
- [ ] 输入法进行中不弹提及菜单
- [ ] 外部请求插入提及时进入同一份草稿，不另起一行
- [ ] 删除一个提及是整块删除，不留下半个名字
- [ ] 对应的源码文本断言已删除，删掉的每一条都能指出接管它的行为断言
- [ ] 逐条实测：故意改坏任一条提及行为时，对应断言失败
- [ ] 全量测试通过
