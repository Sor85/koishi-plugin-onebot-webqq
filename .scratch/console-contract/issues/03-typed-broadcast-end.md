# 03 — 广播端收类型

**What to build:** 广播这个方向从声明到调用到守卫全通。

广播名写错是这条缝上**最坏**的失效形态：完全静默——没有报错，也没有失败提示，只是实时消息不再出现、小胶囊计数停在旧值，看起来像机器人掉线了。而服务端的广播函数现在是「事件名是纯字符串、载荷是 `unknown`」，一处类型都没有。

本票之后，广播名与载荷在编译期被检查，「契约声明了但没人广播」被运行期守卫抓到。

顺带把候选 ⑨ 剩下的那对逐字重复的注册表型控制台替身合并掉——本票无论如何都要动它们，改完再让下一轮回来改同样三处是纯浪费。

**Blocked by:** 02 — 控制台契约表与服务端两处声明。

**Status:** resolved

**参考:** `.scratch/console-contract/spec.md` 的「两端如何接线」与「候选 ⑨ 折进来的边界」；控制台监听器门面为什么存在见它自己的头部注释（Koishi 的注册不返回 disposable，停用插件后旧回调会留在全局）。
