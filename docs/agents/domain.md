# Domain Docs

工程类 skills 探查本仓库前，应按这里读取领域文档和架构决策。

## 探查前读取

- 根目录 `CONTEXT.md`
- 根目录 `docs/adr/`

如果这些文件不存在，静默继续。不要因为缺失就主动要求创建它们；`grill-with-docs` 会在术语或决策真正明确时按需创建。

## 文件结构

本仓库使用 single-context 布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 使用 glossary 中的术语

当输出 issue 标题、重构建议、诊断假设或测试名时，优先使用 `CONTEXT.md` 中定义的领域术语，不要随意换成近义词。

如果需要的概念还没有记录，这通常说明需要重新确认：要么是当前表述偏离了项目语言，要么是领域文档存在缺口，可交给 `grill-with-docs` 进一步澄清。

## 标出 ADR 冲突

如果输出内容与现有 ADR 冲突，必须明确指出，而不是静默覆盖。
